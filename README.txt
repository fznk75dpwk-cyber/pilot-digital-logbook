Pilot Digital Logbook V3.1 PWA
Deploy all files in this directory to HTTPS static hosting (Render Static Site, publish directory .).

IMPORTANT: Offline caching supports opening the app shell only; logging in and reading/saving cloud records require an internet connection.

Payment periods: 21st through following 20th inclusive. Instructor hours from flights.instructor and observed hours from observed_solos.hours. Rates default to LKR 1500 and 1250, respectively. Rates can be adjusted for the displayed calculation but are not persisted. Payments received are tracked by period.

If the Supabase database tables observed_solos and payment_receipts are absent, create them before using this version.
